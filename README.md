# Koleksi Game Edukasi Perpustakaan MAN Tana Toraja

Kumpulan game edukasi berbasis web yang dipublikasikan melalui GitHub Pages.

## Daftar Game
1. **Misi Pustakawan Cilik** — Game edukasi seputar layanan dan literasi perpustakaan.
   - Tautan: `https://perpustakaanmantanatoraja.github.io/misi-pustakawan-cilik.html`
2. **Game Kedua** — *(Ganti dengan judul singkat game kedua)*
   - Tautan: `https://perpustakaanmantanatoraja.github.io/nama-file-game-kedua.html`

## Catatan Pengelolaan File
- Gunakan nama file atau folder dengan huruf kecil dan tanda hubung (`-`), tanpa spasi atau tanda kurung.
- Perbarui daftar di atas setiap kali menambahkan atau mengubah game.
